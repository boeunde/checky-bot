# checky-bot

checky-bot은 공용 Google 캘린더의 일정을 Slack 채널로 보내는 Google Apps Script입니다. 2026년 12월 15일에 종료되는 Slack 채널 캘린더 연결을 대신합니다.

## 동작

- **시작 전 알림:** 5분마다 확인해서, 10분 안에 시작할 일정을 한 번씩 알립니다. 그래서 실제 알림은 시작 5~10분 전에 옵니다.
- **아침 요약:** 평일 오전 9시쯤 오늘 일정을 보냅니다. 일정이 없으면 보내지 않습니다.
- **종일 일정:** 아침 요약에만 나옵니다.
- **일정 변경:** 알림 전에 시간이 바뀌면 바뀐 시간으로 알립니다. 알림 후 시간이 바뀌면 다시 알립니다.
- **보내지 않는 것:** 일정 추가, 수정, 취소 소식은 보내지 않습니다.

## 설치

### 1. Slack Webhook 만들기 (Slack 멤버 아무나)

1. https://api.slack.com/apps 에서 **Create New App**을 누르고, From scratch 아래의 **Pick features**를 고릅니다.
2. 앱 이름(`checky-bot`)과 워크스페이스를 고릅니다.
3. **Incoming Webhooks**를 켜고 **Add New Webhook**을 누른 뒤 알림 받을 채널을 고릅니다.
4. 만들어진 Webhook URL을 복사합니다. 관리자 승인을 요구하면 승인 후 진행합니다.

### 2. 공용 계정 준비 (공용 구글 계정)

1. 공용 계정으로 Google 캘린더에 로그인합니다.
2. 공용 캘린더가 왼쪽 "내 캘린더" 또는 "다른 캘린더" 목록에 있는지 확인합니다. 없으면 추가합니다.
3. 해당 캘린더 설정의 **캘린더 통합**에서 캘린더 ID를 복사합니다.

### 3. 스크립트 설치 (공용 구글 계정)

1. https://script.google.com 에서 **새 프로젝트**를 만들고 이름을 `checky-bot`으로 바꿉니다.
2. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
3. 왼쪽 톱니바퀴(프로젝트 설정)에서 **시간대**가 `(GMT+09:00) 서울`인지 확인합니다. 아니면 바꿉니다.
4. 같은 화면 아래의 **스크립트 속성**에 두 값을 추가합니다.

   | 속성 | 값 |
   |---|---|
   | `CALENDAR_ID` | 캘린더 ID |
   | `SLACK_WEBHOOK_URL` | Webhook URL |

5. 편집기로 돌아와 상단 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다. **배포**는 하지 않아도 됩니다.
6. 권한 요청을 승인합니다.
7. 채널에 "checky-bot이 연결되었습니다" 메시지가 오면 끝입니다.

## 설정 변경

`Code.gs` 맨 위의 `CONFIG`를 고칩니다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| `REMINDER_MINUTES` | `10` | 몇 분 전부터 알릴지 |
| `CHECK_EVERY_MINUTES` | `5` | 확인 주기 (1, 5, 10, 15, 30 중 하나) |
| `DAILY_SUMMARY_ENABLED` | `true` | 아침 요약 사용 여부 |
| `DAILY_SUMMARY_HOUR` | `9` | 아침 요약 시각 |
| `DAILY_SUMMARY_WEEKDAYS_ONLY` | `true` | 주말 요약 생략 |

`CHECK_EVERY_MINUTES`, `DAILY_SUMMARY_ENABLED`, `DAILY_SUMMARY_HOUR`를 바꾸면 `setup`을 다시 실행해야 합니다. 이때 채널에 연결 메시지가 한 번 더 올라갑니다.

## 문제 해결

- **"프로젝트 시간대가 ...입니다":** 프로젝트 설정에서 시간대를 `(GMT+09:00) 서울`로 바꾸고 `setup`을 다시 실행합니다.
- **"캘린더를 찾을 수 없습니다":** ID가 맞는지, 공용 계정의 캘린더 목록에 있는지 확인합니다.
- **"Slack 전송 실패":** Webhook URL을 확인합니다. Webhook을 만든 멤버가 비활성화됐다면 새로 만들어 속성 값을 바꿉니다.
- **제목이 "(제목 없음)"으로 나옴:** 공용 계정의 권한이 "한가함/바쁨만 보기"인지 확인하고, 일정 세부정보를 볼 수 있게 바꿉니다.
- **자동 실행 실패 확인:** 편집기 왼쪽 **실행** 메뉴에서 기록을 볼 수 있습니다. 실패 알림 메일은 공용 계정으로 갑니다.
